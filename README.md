# Field & Signal

Innovative solutions for land, water, and technology. A portfolio by Matthew Longoria, EIT.

Public professional portfolio for civil engineering, GIS, water resources, and AI development, with a résumé, a Kiwami Reader project page, Civil 3D and OpenRoads project sections, ArcGIS and QGIS projects, and future AutoCAD and QGIS plugins.

Website: https://matthewlongoria.github.io/

## Website

The homepage is a self-contained `index.html` with responsive styles and an original conceptual map illustration. It has no build dependencies, analytics, external fonts, or paid services.

GitHub Pages should publish from the `main` branch, `/ (root)`. `.nojekyll` disables Jekyll processing.

## Local development

Open `index.html` in a browser for a quick preview. Edit its HTML and embedded CSS, then review at both desktop and mobile sizes before committing.

## Public content boundary

Every committed file and its Git history are public. This repository is only for approved public website content. Keep proprietary code, employer/client files, private datasets, credentials, and unreleased tools in separate private repositories outside this checkout. `.gitignore` is a convenience, not a security boundary. Check every staged change before pushing.

Future QGIS work is described as planned; no tools or project results are claimed as released. Add public tool links only after release approval.

## Future local workflow

Kiwami Bob integration is deferred. Plan it as a local development integration, with credentials and private projects outside this public repository. No integration is installed or configured by this initial website setup.
